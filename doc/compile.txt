はじめに
--------
	このプログラムが何なのかについては，readme.txt を参照してください。
	このドキュメントでは，auPiECE.kpi をコンパイルする方法を解説します。
	なぜバイナリ配布が行われないのかについても，readme.txt を参照してくださ
	い。

用意するもの
------------
	GNU make
		Win32 版でも Cygwin 版でもお好きなものを。
		私は Cygwin make 3.79.1 で開発しました。
		P/ECE 添付のものはダメです。
	Cygwin 版 gcc / g++ または Borland C++ Compiler 5.5.1
		このどちらかのコンパイラであれば，makefile への変更を最小限で
		済ませることができます。
		Visual C++ をお使いの方は自分でプロジェクトファイルを作ってくだ
		さい :-p
	cp, mv, rm
		必須ではありません。
		make clean や make install を行うときに使います。
	コマンドライン版 zip
		必須ではありません。
		アーカイブファイルを作りたいときは必要です。

準備
----
	この配布ファイル一式をどこかのディレクトリへ展開します。このとき，zip
	のディレクトリ構造を保って展開するようにしてください。必ず新しいディレ
	クトリを作ってそこへ展開してください。展開先は，無難なディレクトリ名に
	しておきましょう。

makefile の修正
---------------
	展開したトップディレクトリ（前項の例では どっか\）の makefile を開き，
		COMPILER=
	の行を，Cygwin でコンパイルするなら cygwin, BCC でコンパイルするなら
	borland と指定します。それ以外のコンパイラをお使いの方は，
	makefile.flags を適当に修正してください（ぉ

	BCC をお使いの方は makefile の修正は必要ありません。

コンパイル
----------
		make
	でコンパイルを開始します。警告がいくつか出ますが無視してください。動作
	に問題はありません。

	コンパイルに成功すると，auPiECE.kpi ファイルが出来上がります。
	このファイルを KbMedia Player の Plugin ディレクトリに放り込んでくださ
	い。makefile.flags の KBMPLAY マクロを編集することにより，
		make install
	でこの作業を行うこともできます。
